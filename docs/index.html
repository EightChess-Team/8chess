The basics

What is 8Chess?

8Chess is a chess engine. It analyzes chess positions, evaluates them, and tries to find the best move. It communicates with chess apps via the UCI protocol.

info string eval: +0.34 (centipawns, side to move)

The engine reports its evaluation (in centipawns) and best move (in UCI notation). Any GUI reads these and displays them to you.

Get started

Works with any UCI-compatible GUI.

Add the downloaded executable as a chess engine in your favorite GUI. 8Chess requires no network file at runtime—the NNUE is already embedded.
