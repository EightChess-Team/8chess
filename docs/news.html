Beta · Source only November 2026

8Chess v2 Beta is out

The v2 beta branch is now public on GitHub. It ships the engine correction pass (qsearch, SEE, draw score, time management, FT gradient fix), SIMD/PGO optimization, and the revived 1024-wide NNUE capacity. Beta builds are source-only — there is no release binary yet. Clone the beta branch and compile from scratch.

Training on the v2 net (1B+ positions, 2×T4) is in progress. A full release with binaries will follow once training and match verification complete.

8Chess 1.0

The first public release. Self-contained Rust chess engine with an embedded 1024-wide NNUE network. No runtime network file required. Available for Linux, macOS, Windows, and Android.
