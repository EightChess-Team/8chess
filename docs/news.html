Release November 2026

8Chess v2 is released

8Chess v2 is out. It ships the engine correction pass (qsearch, SEE, draw score, time management, FT gradient fix), SIMD/PGO optimization (880k nps), Syzygy tablebase support, and the refined NNUE network. Universal binaries are available for Linux, macOS, and Windows — each detects your CPU and uses the best available SIMD automatically. A WebAssembly build is also available for browser play.

Match results vs Stockfish 19 are published in the repository. The v2 branch is now the default.

Release 2026

8Chess 1.0

The first public release. Self-contained Rust chess engine with an embedded 1024-wide NNUE network. No runtime network file required. Available for Linux, macOS, Windows, and Android.
